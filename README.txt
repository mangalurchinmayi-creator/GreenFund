GREENFUND IITG - QUICK START

1. Install Python 3.10 or newer.
2. Extract this ZIP file to a folder.
3. Open Command Prompt / Terminal in that folder.
4. Run:
   pip install -r requirements.txt
5. Run:
   streamlit run app.py
6. Your browser should open the local app.

FEATURES
- Solar calculator: annual solar generation, grid electricity displaced,
  CO2 avoided, investment, bill savings, net savings and simple payback.
- Project updates: progress text, funding/spending fields and uploads
  for photos, videos, invoices and reports.
- Investor review: reviewer can record Approved by reviewer or Changes requested.

IMPORTANT LIMITATIONS
- This is a classroom/demo prototype. It does not have secure user accounts,
  remote cloud storage, real investor authentication, or legally binding approvals.
- Uploaded files and update records are stored locally in the app folder.
- Replace all demo values with sourced campus data and current official emission
  factors before presenting any result as an IIT Guwahati estimate.
- The default grid emission factor is only a placeholder for demonstrating
  the calculator. Cite the official source and year used in your project report.
- Payback is simple payback; it excludes financing interest, degradation,
  equipment replacement, export compensation and other detailed cash flows.
